Full archive and code

  • Zenodo archive — the original frozen snapshot (all tables on the original basis, plus the record-level country-parse table for 392,456 records, the GBD input extracts, reference tables, all production and figure code, and the project documents). The original formulations' results are retained there as the sensitivity basis for the corrected basis: doi.org/10.5281/zenodo.24418492.
  • Corrected-basis archive — Amendment v1.2 and the fix round's evidence files (precise formulations, mapping table, PPV audit, headline survival table) are in the OSF project's frozen-archive folder: doi.org/10.17605/OSF.IO/NUC4B.
  • Production code — search formulations, GBD mapping, parsing and indicator code, figure scripts and this site's generator are archived together with the frozen data in the Zenodo record above: doi.org/10.5281/zenodo.24418492.
  • Preregistration — protocol and Amendments v1.1 (GBD 2023) and v1.2 (formulation correction): doi.org/10.17605/OSF.IO/NUC4B.

Record-level Europe PMC metadata remain available from Europe PMC; GBD 2023 estimates remain available from the Institute for Health Metrics and Evaluation. This site redistributes only this study's frozen derived tables.
